# typescript-knowledge

Agent Skill для разработки на TypeScript в любой области: веб-приложения и сайты, библиотеки, монорепозитории, мобильные и десктопные приложения, браузерные игры, визуализация, расширения, edge и AI-приложения.

Скилл даёт ИИ-агенту (Claude Code, claude.ai и другим инструментам с поддержкой формата [Agent Skills](https://agentskills.io)) три вещи:

- **библиотеку знаний** — более тысячи ссылок на книги, статьи, доклады, документацию и кодовые базы, разложенных по категориям, с пояснением, зачем читать каждый источник;
- **тулчейн** — TypeScript 6 и 7, `tsconfig`, диагностика медленной проверки типов, сборщики, линтеры, порядок шагов в CI;
- **пайплайн** — тесты до кода, проверки качества, бенчмарки, базовый замер, ревью, поиск решений в библиотеке, оптимизация и повторный замер. Правка оптимизации принимается, только если замер показал выигрыш и другие оси не ухудшились.

Состояние знаний — ноябрь 2026: TypeScript 7.0.2 и 6.0.3, 7.1 в бете. Тексты справочников на русском, названия источников в оригинале.

Серверный Node.js (event loop, HTTP-фреймворки, базы данных) вынесен в отдельный скилл [node-knowledge](https://github.com/Betreazen/node-knowledge-skill).

## Состав

```text
typescript-knowledge/
├── SKILL.md                    точка входа: куда смотреть и как работать
├── references/
│   ├── pipeline.md             пайплайн разработки и оптимизации
│   ├── toolchain.md            компилятор, tsconfig, сборщики, линтеры, CI
│   ├── types-patterns.md       система типов, паттерны, антипаттерны, чеклист ревью
│   ├── performance.md          оптимизация: таблица «симптом → техника → источник»
│   ├── benchmarking.md         как мерить: инструменты, статистика, профилирование
│   ├── testing.md              стек тестирования и чеклист ревью тестов
│   ├── architecture.md         структура проектов, границы, монорепозитории
│   ├── frontend.md             React, Vue, Angular, Svelte и другие
│   ├── domains.md              мобильные, десктоп, игры, edge, AI, Wasm и другое
│   ├── books.md                индекс, короткий список и маршрут чтения
│   └── books-*.md              книги, блоги и курсы по темам
└── scripts/
    ├── bench_template.mts      шаблон бенчмарка с прогревом JIT
    ├── bench_template_nodeps.mts  запасной шаблон без зависимостей
    ├── bench_compare.mjs       сравнение прогонов «до» и «после» с учётом шума
    └── tsc_diag.mjs            счётчики tsc --extendedDiagnostics в JSON
```

Агент загружает `SKILL.md`, когда задача касается TypeScript. Справочники он открывает только тогда, когда нужен конкретный раздел, поэтому скилл почти не занимает контекст, пока не используется.

## Установка

**Claude Code: для всех проектов.** Скопируйте папку `typescript-knowledge` в `~/.claude/skills/`.

**Claude Code: для одного проекта.** Скопируйте папку `typescript-knowledge` в `.claude/skills/` в корне проекта и закоммитьте её. Тогда скилл получит вся команда.

**claude.ai.** Заархивируйте папку `typescript-knowledge` в zip и загрузите в разделе Skills настроек claude.ai.

**Другие агенты (Codex, Gemini CLI, GitHub Copilot, Cursor).** Скопируйте папку в `.agents/skills/` проекта.

## Использование

Скилл срабатывает сам, когда задача касается TypeScript. В Claude Code его можно вызвать и явно командой `/typescript-knowledge`.

Примеры запросов:

- «Проведи цикл оптимизации этого модуля: бенчмарки, базовый замер, ревью, гипотезы из библиотеки, повторный замер»
- «Проверка типов занимает две минуты, найди причину и ускорь»
- «Бандл вырос до 800 кБ, что можно убрать?»
- «Какую структуру выбрать для монорепозитория на 20 пакетов?»
- «Сделай ревью типов по чеклисту»
- «INP на странице каталога 400 мс, что делать?»

## Пометки в справочниках

- `[устарело]` — у материала есть замена, и она указана рядом.
- `[не проверено]` — утверждение взято из одного вторичного источника; его стоит перепроверить.
- `[проверено локально]` — результат получен запуском на одной машине, версии указаны рядом.

Версии указаны на ноябрь 2026. Со временем они устаревают, поэтому перед важными решениями сверяйтесь с npm и release notes.
